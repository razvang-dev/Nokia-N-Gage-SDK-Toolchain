# Third-Party Components

The MIT License in the repository root applies only to original project material for which this project can grant that license.

This development environment also contains or interfaces with historical third-party components, including Nokia / Symbian / Series 60 SDK material, GCC and GNU binutils-derived cross-development components, GnuPoc-related material, and associated development utilities.

Those components are not relicensed by the project. Their original copyright notices, license files and source notices should be preserved with redistributed copies. Where a third-party source tree or archive contains its own license/readme file, that file is authoritative for that component.

Notable component families include:

- Series 60 / Symbian OS 6.1 SDK headers, libraries, examples and development utilities
- GCC 539 / `2.9-psion-98r2` ARM EPOC PE compiler components
- ARM EPOC PE binutils
- GnuPoc-related build/tooling material
- Resource, bitmap, AIF, E32-image and SIS utilities included with the development environment

The `sources/` and `ngage-toolchain/` directories retain upstream source archives and/or their accompanying notices where available.

When redistributing this toolchain, preserve this file, the root `LICENSE`, and all license/readme/copyright files included with third-party components.
